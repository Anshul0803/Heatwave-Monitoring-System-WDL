# THERMOSCOPE — Heatwave Intelligence Portal

A polished multi-page climate monitoring website with an original dark-glass interface.

## Pages
- Overview
- Heatwave Alerts
- Regional Hotspots
- Forecast
- Climate Analytics
- Registration & Alert Preferences
- Advisory Subscription
- Sources & Stakeholders
- Heat Safety Studio
- Live Alert Controls

## Tech
HTML5, CSS3, JavaScript and jQuery.

## Run
Open `index.html` in a browser. Internet access is only needed for the CDN-hosted jQuery library and the embedded map.
